# 家族連絡メモのQRコード表示・LINE共有機能 実装計画

家族の集合場所や緊急連絡先メモを、家族全員のスマートフォン間で簡単に共有・バックアップできるように強化します。

---

## 1. 実装する主な機能

### A. LINE・メッセージワンタップ共有
- **LINEで家族に送る**:
  - `https://line.me/R/msg/text/` スキームを使用し、登録された「集合場所」「家族連絡先」「自宅住所」「特記事項メモ」「災害伝言ダイヤル171の案内」を整形したテキストとしてLINEトークにワンタップで送信。
- **Web Share API & テキストコピー**:
  - iPhone / Androidの標準共有シート（メール、SMS、メモ帳など）を起動。非対応環境ではクリップボードにコピーして完了トーストを表示。

### B. QRコード生成 & カメラ読み取り
- **オフライン完結型QRコード（`qrcode` パッケージ）**:
  - 外部APIに依存せず、ブラウザ内で完結してQRコードを描画。
  - 家族が自分のスマホのカメラ（標準カメラアプリ）をかざすだけで、登録された防災連絡メモが一瞬で画面に表示・読み取り可能。
- **QRコード画像保存（PNGダウンロード）**:
  - 生成されたQRコードを画像としてスマホの写真アルバムに保存でき、通信途絶時でもロック画面や写真フォルダからいつでも提示可能。

---

## 2. 画面レイアウト（UI設計）

- 「💾 保存する」ボタンの直下に、分かりやすい **【家族と共有する】** アクションカードを追加：
  - `🟢 LINEで家族に送信`（LINEカラーの大きな共有ボタン）
  - `📲 QRコードを表示`（タップすると大きくQRコードが展開されるモーダル）
  - `📋 メモをコピー`（クリップボードへ保存）
- 未入力時には「※集合場所や連絡先を入力・保存すると共有できます」と親切にガイド。
