# 🚨 防災アプリ (Disaster Preparedness & Alerts)

気象庁（JMA）のリアルタイム防災情報XMLと国土地理院地図を連携した、総合防災支援React Webアプリケーションです。

## 主な機能

1. **🚨 災害速報**
   - **地震情報**: 気象庁XMLフィードから最新の発生時刻、震源地、最大震度、マグニチュード、注意警戒情報を取得・表示。震度別カラーコーディング（緑・黄・橙・赤・濃赤）。手動更新ボタンおよび5分毎の自動更新。
   - **津波情報**: 気象庁の津波警報・注意報・予報の発表状況をリアルタイム表示。
   - **気象警報・注意報**: 全国47都道府県を選択可能。特別警報（黒）、危険警報（紫）、警報（赤）、注意報（黄）、発表なし（緑）の5段階レベル判定と詳細発表内容を表示。
   - **総合危険度表示**: 画面上部に最新の危険度ステータスを即時案内。

2. **🏃 避難場所**
   - **現在地検索**: ブラウザのGeolocation APIを用いて現在地周辺の避難所をGoogle マップで即座に検索。
   - **国土地理院 防災地図**: アプリ内に国土地理院（GSI）の公式防災地図を埋め込み表示。
   - **指定避難施設**: 学校、公民館、体育館などの施設別マップリンク。

3. **🎒 防災チェック**
   - 水・飲料水、非常食、懐中電灯、モバイルバッテリー、救急用品、ティッシュ・タオル、防寒具、マスクの8項目。
   - チェック状態を端末内（`localStorage`）に永続保存。準備進捗プログレスバー付き。

4. **📖 災害時の行動**
   - 地震、津波、大雨・洪水、火災の4大災害における初動マニュアルと避難手順をわかりやすく整理。

5. **👨‍👩‍👧 家族との連絡**
   - 集合場所、家族の連絡先、自宅住所、非常時メモを登録・保存。
   - 端末ローカルストレージへ保存され、災害時オフラインでも確認可能。

6. **🧠 防災クイズ**
   - 4択クイズ形式で防災初動や備蓄の基礎知識を学べるインタラクティブクイズ機能。

## 技術スタック

- **フロントエンド**: React 19, TypeScript, Tailwind CSS
- **ビルドツール**: Vite
- **バックエンド**: Express (TypeScript / Node.js) - 気象庁JMA XMLフィードプロキシおよびパーサー（`fast-xml-parser`）
